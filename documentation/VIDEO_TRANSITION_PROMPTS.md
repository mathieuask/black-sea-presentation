## Commandes ffmpeg (après génération)

Découper une vidéo en frames PNG :
```bash
ffmpeg -i transition_01.mp4 -vf "fps=30" frames/transition_01/frame_%04d.png
```

Découper en WebP (plus léger) :
```bash
ffmpeg -i transition_01.mp4 -vf "fps=30,scale=1920:1080" frames/transition_01/frame_%04d.webp
```

Adapter le numéro (transition_01, transition_02...) pour chaque vidéo.

## Si le résultat n'est pas bon

Ajouter à la fin du prompt selon le problème :
- Trop réaliste → ajouter `low-poly stylized rendering`
- Globe pas assez clean → ajouter `flat shading, no texture details`
- Bordures invisibles → ajouter `clearly visible white country border outlines`
- Trop de détails → ajouter `extremely minimal, no clouds, no atmosphere glow`
